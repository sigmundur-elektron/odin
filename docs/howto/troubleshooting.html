Troubleshooting

What the exit codes mean, and where to look first.

Exit codes

CodeMeansExample
0SuccessA run reached complete.
1Nothing found — a query miss, not a failureauth list with an empty store; doctor with nothing reachable.
2Failure; message on stderrBad config, invalid task, or a run that ended blocked.
Scripting note. Do not treat 1 as an error. odin doctor; if [ $? -ne 0 ] will fire on a perfectly healthy machine that simply has no provider configured yet.

Common failures

odin: command 'adapters.x'.type '...' is not a built-in adapter kind

Valid values are command, mock, openai-compatible and cli-agent. An unknown type is refused at load rather than treated as command, so a typo surfaces here instead of as a missing-executable error mid-run.

odin: command 'adapters.x' is type 'openai-compatible' and needs 'base_url'

An HTTP adapter has no endpoint. Add base_url, or get one from odin doctor --emit-config.

odin: odin's runtime assets were not found under <path>

The installation is incomplete — the executable cannot find its share/odin assets. Re-run cmake --install, or set ODIN_RUNTIME_ROOT to override.

adapter '...' failed to run: The system cannot find the file specified

The adapter command's executable does not exist or is not on PATH. Run odin doctor --deep; if the tool is found but off PATH, use the absolute path it reports.

adapter '...' returned invalid JSON

The model produced nothing recoverable. Odin already tries the whole reply, fenced blocks, and balanced brace spans before giving up. Usually means the model is too small for the task, or a cli-agent has the wrong text_path for its event stream. The error carries a bounded preview of what came back.

The run ended blocked

A stage exhausted its attempts, or the transition budget ran out. Read context.json for the history and the last handoff's findings. If it is the gate, run the gate command yourself — it is an ordinary command.

credential '...' has expired

An imported OAuth token is past its expiry. Refresh it in the tool that issued it and re-import, or store a plain key with odin auth set.

changed_files artifact is invalid

The implementer returned paths that are absolute, contain traversal, name directories, are duplicated, or resolve outside the project root. Odin refuses to stage them. The findings name the offending entry.

Where to look

QuestionLook at
What did each stage decide?.odin/runs/<id>/context.json → history
What exactly did the gate print?the gate artifact in that history
Where did it stop and why?state.json → status, current_stage, reason_code
Was a stage interrupted?journal/ — an unmatched stage_started
Is my configuration understood?odin models and odin validate
Is the provider reachable?odin doctor, then --deep
Secrets are already redacted. Run directories are safe to attach to a bug report: captured output has stored and explicitly imported credentials removed in raw, JSON-escaped and ASCII-escaped forms before anything is written.

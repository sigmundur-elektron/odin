Store a credential

Use a hosted provider without the key reaching argv, logs, or durable state.

1Store one

odin auth set openrouter          # prompts; input is not echoed
odin auth set openai --stdin      # read from a pipe, for scripts
odin auth set local --value ...   # discouraged; see below
odin auth list                    # values masked
odin auth remove openrouter
Avoid --value. It puts the secret in your shell history and in the process listing, which on most systems any process of the same user can read. It exists for non-interactive edge cases; prefer --stdin.

The store lives at .odin/credentials.json, inside gitignored .odin/. It is created owner-only: mode 0600 on POSIX, an explicit current-user DACL on Windows.

2Import an existing token

Already authenticated somewhere else? Import rather than logging in again:

odin auth import --from-file ~/.local/share/opencode/auth.json --provider github-copilot
odin auth import --from-file ./tokens.json --provider openai --name work-openai

Odin reads access, value or token, whichever the file uses. An entry carrying refresh or expires is stored as OAuth and keeps those fields, so expiry can be reported rather than discovered as a provider rejection.

github-copilot   oauth    gho...3456   [valid]     imported from auth.json
stale-provider   oauth    gho...0abc   [EXPIRED]   imported from auth.json

3Reference it by name

Nothing secret enters the repository or odin.toml:

[adapters.hosted]
type = "openai-compatible"
base_url = "https://openrouter.ai/api/v1"
credential = "openrouter"

For a cli-agent, name the variable the child should receive it in. The value is injected into the child environment, never onto its command line:

[adapters.cli]
type = "cli-agent"
command = ["my-agent", "run", "--model", "{model}"]
credential = "openrouter"
credential_env = "OPENROUTER_API_KEY"

A credential named github-copilot is overridden by ODIN_CREDENTIAL_GITHUB_COPILOT.

What is guaranteed

PropertyHow
Never in argvAdapters get a name and read the value themselves.
Never in outputauth list, doctor and all reports render through masking. Twelve characters or fewer is replaced entirely.
Never in state filesCaptured stdout and stderr are redacted in three forms — raw, JSON-escaped, and ASCII-escaped — before anything durable is written.
Owner-only on disk0600 on POSIX; a protected current-user DACL on Windows.
Expired tokens fail loudlyRefused with a message naming the fix rather than sent and rejected.
An honest limit. These stop accidental echoes. They do not sandbox a child process: arbitrary same-user code can still read a project-local credential store. Full isolation needs a credential broker or container boundary, which does not exist yet.

Link a model

Configure against what this machine can actually reach, not against a remembered name.

1Probe

odin doctor

Probes four transports with short timeouts and no dependencies:

TransportCoversProbe
OpenAI-compatible HTTPOllama, LM Studio, llama.cpp, vLLM, LiteLLM, OpenAI, Azure, OpenRouter, Groq, Together, DeepSeekGET /v1/models
Ollama nativelocal models plus parameter size and quantizationGET /api/tags
Agent CLIOpenCode, Claude Code, Aider, Codex, llmbinary on PATH, and off it
Hosted keyany provider whose credential is presentenvironment variable

Statuses: ready, auth-required (reachable, key rejected), error, unreachable.

odin doctor --deep                 # also enumerate agent CLI models
odin doctor --deep --path <dir>    # look in a directory Odin does not know
odin doctor --json                 # machine-readable
Found but not on PATH? Discovery also searches npm global prefixes, Scoop and WinGet shims, ~/.local/bin, %LOCALAPPDATA%\Programs, project node_modules/.bin, and .odin/tools. It reports the absolute path so you can use it directly.

2Emit configuration

odin doctor --emit-config

Writes paste-ready blocks from what was observed, so model ids are never guessed:

[adapters.http-ollama]
type = "openai-compatible"
base_url = "http://127.0.0.1:11434/v1"
timeout_seconds = 900

[models.qwen2-5-coder-32b]
adapter = "http-ollama"
model = "qwen2.5-coder:32b"
parameter_billions = 32.8
tags = ["ollama", "discovered"]

Always exits 0, so it is safe to redirect. Adding a provider is configuration, not code.

3Adapter kinds

openai-compatibleany endpoint speaking the OpenAI shapebase_url (required), api_key_env, credential, temperature, json_mode

A hosted provider using a stored credential:

[adapters.hosted]
type = "openai-compatible"
base_url = "https://openrouter.ai/api/v1"
credential = "openrouter"
timeout_seconds = 900

A streaming agent CLI:

[adapters.cli]
type = "cli-agent"
command = [".odin/tools/opencode/node_modules/.bin/opencode",
           "run", "--model", "{model}", "--format", "json"]
output = "jsonl"
text_path = "part.text"
prompt_stdin = true
timeout_seconds = 1800
Set prompt_stdin for large contexts. By default the prompt is appended as the final argument, which can exceed the command-line length limit — 32767 characters on Windows.

4Route roles to profiles

Roles fall back to default when unlisted. This is where cost is traded against capability per stage:

[routing]
default     = "coder-32b"
analyst     = "frontier"
reviewer    = "frontier"
implementer = "coder-32b"
verifier    = "coder-32b"
odin models          # what is configured
odin models --json
Routing names a profile directly. Capability-based routing — declaring what a role needs and letting Odin resolve it with fallback — is future work.
